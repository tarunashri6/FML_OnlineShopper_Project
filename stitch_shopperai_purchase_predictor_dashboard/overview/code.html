Key Research Findings

Core insights deduced from cross-model evaluation & feature attribution matrices

Derived from 48 Empirical Trials
monetization_on
Insight 01 SHAP Weight #1

PageValues is the Dominant Predictor

Sessions with PageValues > 0 exhibit a 68% purchase conversion rate compared to <4% for unmonetized sessions. It accounts for over 45% total relative feature importance.

Impact Magnitude Extreme (p < 0.001)
account_tree
Insight 02 Variance Reduction

Ensemble Methods Outperform Single Classifiers

Random Forest achieved superior precision-recall balance (F1: 0.664), substantially reducing false positives compared to standalone Decision Trees which suffered from decision-boundary overfitting.

Generalization Gap +0.075 F1 over CART
balance
Insight 03 Resampling Criticality

Addressing Class Imbalance is Essential

Without resampling or class weighting, standard models defaulted to predicting 'No Purchase' with 88% naive accuracy but near-zero minority recall (0.19). SMOTE balanced sensitivity reliably.

Recall Recovery +256% True Positives
