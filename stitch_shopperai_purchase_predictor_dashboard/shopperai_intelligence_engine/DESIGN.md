## Brand & Style
The design system embodies enterprise-grade predictive analytics and academic machine learning rigor. It bridges high-stakes decision intelligence with executive clarity, tailored for data scientists, e-commerce growth directors, and viva evaluators.

The aesthetic fuses **Corporate / Modern precision** with **High-Density Technical Utility**:
- **Cognitive Authority:** Clean architectural grids, pristine white surface cards, restrained micro-borders, and high-legibility tabular telemetry convey empirical trust and statistical reliability.
- **Explainability First:** Visual treatments prioritize interpretability (SHAP attributions, ROC/AUC metrics, probability bands) over purely decorative flourishes.
- **Controlled Contrast:** A dual-plane canvas pairing an obsidian deep navy shell for navigation and toolbars against an airy, light-slate workspace engineered for prolonged analytical sessions.

## Colors

The palette establishes strict semantic clarity to differentiate predictive certainty, attribution polarity, and structural framework:

### Canvas & Structurals
- **Canvas Base:** `#F8FAFC` (Slate 50) establishes a low-fatigue workspace.
- **Sub-canvas / Neutral Groupings:** `#F1F5F9` (Slate 100) provides nested panel contrast.
- **Surface Elevation:** `#FFFFFF` (Pure White) houses cards, charts, and modal components.
- **Structural Outlines:** `#E2E8F0` (Slate 200) for borders and `#CBD5E1` (Slate 300) for control dividers.
- **Sidebar & Executive Anchors:** `#0F172A` (Slate 900) for high-contrast command surfaces and `#1E293B` (Slate 800) for elevated sidebar tiles.

### Primary Accent
- **Interactive Blue:** Primary action `#2563EB` (Blue 600) with interactive hover `#1D4ED8` (Blue 700) and focused wash `#DBEAFE` (Blue 100).

### Semantic & Machine Learning Classifiers
- **Purchase / High Intent / Positive Feature Attribution:**
  - Solid: `#10B981` (Emerald 500), Active/Hover: `#059669` (Emerald 600)
  - Surface Pill / Soft Container: `#D1FAE5` (Emerald 100), Text: `#065F46` (Emerald 800)
- **No Purchase / Low Intent / Negative Feature Attribution:**
  - Solid: `#EF4444` (Red 500), Active/Hover: `#DC2626` (Red 600)
  - Surface Pill / Soft Container: `#FEE2E2` (Red 100), Text: `#991B1B` (Red 800)
- **Indeterminate / Threshold Alert / Drift:**
  - Solid: `#F59E0B` (Amber 500), Soft Container: `#FEF3C7` (Amber 100), Text: `#92400E` (Amber 800)

## Typography

The type system coordinates authoritative geometric branding headers via **Plus Jakarta Sans** with high-density, analytical legibility delivered through **Inter**.

### Tabular Formatting Directive
- All numerical figures, percentages, log loss outputs, confidence scores, and SHAP delta values require `font-feature-settings: "tnum" 1, "cv05" 1`. This guarantees alignment across tabular grids, probability progress rows, and split metrics.
- All micro labels (`label-sm`) designated for feature attributions and metric badges are rendered uppercase with intentional tracking (`0.05em`).

## Layout & Spacing

The dashboard employs a fluid-responsive column grid backed by an immutable 4px/8px spatial scale.

### Layout Model
- **Command Shell:** Fixed 260px desktop navy sidebar expanding into a 12-column adaptive workspace with `gutter` (1.5rem) and `margin` (2rem).
- **Density Adaptation:** High-density statistical views (e.g., confusion matrix, live feature weights) drop internal component padding to `space-sm` while maintaining overall card separation at `space-md`.
- **Breakpoints:**
  - Desktop (`>= 1280px`): Full 12-column analytical canvas. Parameter inputs and SHAP output split 4:8 or 5:7.
  - Tablet (`768px - 1279px`): 8-column canvas. Collapses sidebar to an icon dock (64px). Metrics reflow into a 2x2 matrix.
  - Mobile (`< 768px`): 4-column flow. Outer margins drop to `margin-mobile` (1rem). Gaps compress to `gutter-sm` (1rem). Tool panels stack above inference outputs.

## Elevation & Depth

Visual hierarchy leverages low-contrast outlines coupled with ambient, cool-tinted micro-shadows to ensure focus rests on empirical data rather than heavy artificial shadows:

- **Level 0 (Canvas Base):** Flat `#F8FAFC`, no shadow.
- **Level 1 (Card & Modular Panels):** `#FFFFFF` background, a 1px border (`#E2E8F0`), and an ultra-subtle tinted shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.03)`.
- **Level 2 (Hover Surfaces & Dropdowns):** 1px border (`#CBD5E1`), elevated shadow: `0 4px 6px -1px rgba(15, 23, 42, 0.06), 0 2px 4px -2px rgba(15, 23, 42, 0.04)`.
- **Level 3 (Modal Dialogs & Flyout Explainers):** 1px border (`#CBD5E1`), floating shadow: `0 20px 25px -5px rgba(15, 23, 42, 0.08), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`.
- **Feature Layering:** SHAP attribution waterfall segments and probability gauges sit embedded inside cards using `#F1F5F9` recessed wells with `box-shadow: inset 0 1px 2px 0 rgba(15, 23, 42, 0.04)`.

## Shapes

The design system maintains a **Soft** shape language (`roundedness: 1`), projecting engineered accuracy:

- **Inputs, Buttons, and Stat Badges:** `rounded` (0.25rem / 4px) to retain technical structure and clean alignment.
- **Data Cards, Modals, and Charts:** `rounded-lg` (0.5rem / 8px) to soften external dashboard blocks.
- **Progress Wells and Threshold Dividers:** `rounded-lg` (0.5rem / 8px) with internal track fills matching the parent radius.
- **Status Pills and Attribution Delta Badges:** Fully rounded (`9999px`) to immediately distinguish real-time classification tags from square tabular metrics.

## Components

### Buttons & Interactive Triggers
- **Primary Inference Button:** Solid `#2563EB` fill, white typography (`label-lg`), 8px 16px padding, subtle transition (`transform 0.1s ease`). On active click: `#1D4ED8`. Focus outline: 2px `#2563EB` with 2px offset.
- **Secondary / Export:** `#FFFFFF` surface, 1px border `#E2E8F0`, text `#1E293B`. Hover shifts to `#F8FAFC` and border `#CBD5E1`.
- **Tertiary Utility:** Transparent background, text `#64748B`, hover to `#F1F5F9`.

### Segmented Controls (Classifiers & Model Switches)
- Recessed container (`#F1F5F9`) with 4px inner padding.
- Selected tab: Pure white pill (`#FFFFFF`), `rounded` (4px), faint shadow (`0 1px 2px rgba(15, 23, 42, 0.06)`), text `#0F172A` (`label-md`).
- Unselected tab: Transparent, text `#64748B`, transition on hover to `#0F172A`.

### Input Panels & Session Sliders
- **Text & Numeric Inputs:** Pure white surface, 1px border `#E2E8F0`, padded at 8px 12px. Placeholder text `#94A3B8`. Tabular numeric presentation. Focused state shifts border to `#2563EB` with a `0 0 0 3px rgba(37, 99, 235, 0.15)` halo.
- **Range Sliders (ExitRates, BounceRates, Administrative Duration):** 6px track `#E2E8F0`, filled progression `#2563EB`. Slider thumb: 16px white circle with 2px solid `#2563EB` and elevation Level 2.

### Probability Gauges & Progress Meters
- Dual-polarity confidence bar: Centered baseline for threshold analysis or 0-100% full horizontal distribution.
- Track height: 10px inside nested card wells.
- High intent purchase prediction values (`>= 0.50`) animate with `#10B981`. Low intent (`< 0.50`) fills with `#EF4444`. Includes a distinct marker overlay denoting the classification decision boundary (default `0.50`).

### SHAP Explainability Bars
- **Attribution Rows:** Grid row containing feature title (`body-sm`), numerical impact delta (`metric-tabular`), and bilateral visual distribution bar.
- **Positive SHAP (+ Impact toward Purchase):** Bar anchored from midpoint rightwards using `#10B981`. Paired badge in `#D1FAE5` with `#065F46` label.
- **Negative SHAP (- Impact toward Non-Purchase):** Bar anchored from midpoint leftwards using `#EF4444`. Paired badge in `#FEE2E2` with `#991B1B` label.

### Statistical Stat Badges & Metric Cards
- **Stat Cards:** White canvas, 1px `#E2E8F0` border, 16px internal padding. Houses category label (`label-sm`, uppercase), primary score (`metric-display`, tabular), and semantic differential badge.
- **Semantic Badges:** Pill shape, 4px 8px padding, containing icon indicator and text (`label-sm`).
